INSTALLATION // MACOS

Install in 10 seconds

Download TickBar-macOS-Universal.dmg, drag TickBar.app into your Applications folder, and launch. If macOS Gatekeeper prompts on first launch, run the one-liner on the right or right-click → Open.

Download TickBar-macOS-Universal.dmg
# Optional: Open DMG & clear Gatekeeper quarantine attribute
$ hdiutil attach ~/Downloads/TickBar-macOS-Universal.dmg
$ cp -R "/Volumes/TickBar/TickBar.app" /Applications/
$ xattr -cr /Applications/TickBar.app && open /Applications/TickBar.app
